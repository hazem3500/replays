# Theme token contract

Generated by `node scripts/theme-contract.mjs` from `src/shared/theme-tokens.ts`.

Set these through `theme.dark`, `theme.light` or trusted `api.branding({ theme })`. Each name maps to
a CSS custom property with a `--` prefix. Names are added, never renamed. Values must be plain CSS
without URLs, comments or declaration delimiters. Defaults live in `styles.css` and `theme-tokens.css`;
caption defaults also work in the standalone video renderer. Reduced-motion and forced-color rules
continue to take precedence. Set background and foreground pairs together and check contrast.
