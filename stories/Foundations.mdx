## Tokens are the source of truth

The **Tokens** stories discover CSS custom property names from the actual app stylesheets, then read their resolved values from the rendered document. The light theme is a toolbar switch away. A token change in the app is reflected here without editing a copied palette.

The app does not yet expose a shared spacing-token scale. The Spacing story calls that out explicitly; it does not invent a second scale for Storybook.
